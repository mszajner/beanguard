# BeanGuard

BeanGuard is a licensing system for Java applications built on Spring Boot. It issues, encrypts, and verifies licences — you decide which limits and features each one unlocks. {{ className: 'lead' }}

## What it's made of

BeanGuard is four independent modules — run them on their own via Docker, or integrate them into your own application via Maven:

- **[Licence server](/en/server)** (`beanguard-server`) — REST API and a PostgreSQL database. Issues licences and stores the cryptographic keys.
- **[Admin panel](/en/admin-panel)** (`beanguard-admin`) — manage licences, orders, shop products, branding, and the rest of the server's configuration.
- **[Shop](/en/shop)** (`beanguard-shop`) — a public storefront where your customers buy and activate licences themselves.
- **[Client integration](/en/client)** (`beanguard-client`) — a Spring Boot library you add to your application to enforce the limits and features from a purchased licence.
