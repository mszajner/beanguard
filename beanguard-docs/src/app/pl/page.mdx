# BeanGuard

BeanGuard to system licencjonowania dla aplikacji Java opartych o Spring Boot. Wydaje, szyfruje i weryfikuje licencje — Ty decydujesz, jakie limity i funkcje odblokowuje każda z nich. {{ className: 'lead' }}

## Z czego się składa

BeanGuard to cztery niezależne moduły — uruchamiasz je samodzielnie przez Docker albo integrujesz z własną aplikacją przez Maven:

- **[Serwer licencji](/pl/serwer)** (`beanguard-server`) — REST API i baza PostgreSQL. Wydaje licencje i przechowuje klucze kryptograficzne.
- **[Panel admina](/pl/panel-admina)** (`beanguard-admin`) — zarządzanie licencjami, zamówieniami, produktami sklepu, brandingiem i resztą konfiguracji serwera.
- **[Sklep](/pl/sklep)** (`beanguard-shop`) — publiczna witryna, w której Twoi klienci samodzielnie kupują i aktywują licencje.
- **[Integracja klienta](/pl/klient)** (`beanguard-client`) — biblioteka Spring Boot, którą dodajesz do swojej aplikacji, aby egzekwowała limity i funkcje z wykupionej licencji.
